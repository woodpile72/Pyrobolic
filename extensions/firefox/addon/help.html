A shorter path to your downloads.

Pyrobolic for Firefox · 1.0.0

Connect the desktop app

  1. Install Pyrobolic 1.2.0 or newer.
  2. The Pyrobolic Debian package includes the browser bridge.
  3. Open this extension again. The footer should say “Pyrobolic ready.”

Send a page, link or media

Open the toolbar popup and choose Send to Pyrobolic. You can edit the address first. Or right-click a page, link, video or audio player and use its Pyrobolic menu item.

The app opens a download review. Choose your format and options there; sending a link does not start a download. If another download dialog is open, the new link waits until you close it.

For browser-only media addresses such as blob:, we send the containing page instead. Site support comes from Pyrobolic and yt-dlp; this extension does not detect hidden streams or bypass protected media.

If the app does not open

Open Pyrobolic from your application menu to confirm it is installed. Check that Pyrobolic 1.2.0 or newer is installed for the same machine. An exclamation mark on the toolbar icon means a send failed; open the popup for details.

This preview targets native Firefox on Linux Mint, Cinnamon and GNOME. Flatpak and Snap Firefox may isolate the native bridge and are not supported by this package yet.

Privacy

Only addresses you explicitly send are passed to the local desktop app. The extension does not read cookies, scan your browsing history, monitor the clipboard, intercept downloads, or send analytics. The toolbar reads the current tab only when you use it. Context menu actions receive the address you selected. Pyrobolic’s own network and authentication choices apply after handoff.

“Ready” confirms the bridge and installed launcher are available. Sending confirms launch was requested, not that a media download succeeded.

Install in Firefox

Install the Mozilla-signed Firefox XPI from the Pyrobolic GitHub release using Firefox’s Add-ons Manager: choose Install Add-on From File. A copy is included at /usr/share/pyrobolic/extensions/firefox/pyrobolic-firefox.xpi. This extension is distributed by Pyrobolic and is not listed on Mozilla’s public add-on site.

Private windows

In about:addons, select Pyrobolic → Run in Private Windows → Allow. Firefox requires your permission. Downloads you submit still use Pyrobolic’s normal history.

Updates and removal

For this release, install newer signed XPIs from Pyrobolic’s release page manually. Updating the Debian package updates its bundled copy, but does not replace an extension already installed in your Firefox profile. Remove the extension through Firefox’s Add-ons Manager. Removing the Pyrobolic Debian package removes its browser bridge; your downloads and settings are retained.
